WHAT GETS GENERATED
═══════════════════════════════════════════════════════════════════════

After running MasterRunner:

✅ experiment1/results.csv  ← Linear List performance data
✅ experiment2/results.csv  ← AVL Tree performance data  
✅ experiment3/results.csv  ← RBT performance data

Each CSV contains:
• Data Size
• Insertion Time (ms)
• Search Time (ms)
• RBAR Calculation Time (ms)
• Top-K Retrieval Times (ms)
• Tree Statistics (height, balance)


═══════════════════════════════════════════════════════════════════════
PERFORMANCE COMPARISON
═══════════════════════════════════════════════════════════════════════

Operation           Linear List    AVL Tree      RBT
────────────────────────────────────────────────────────────
Insert              O(1)           O(log N)      O(log N)
Search              O(N)           O(log N)      O(log N)*
Top-K Retrieval     O(N log N)     O(N log N)    O(k)**
RBAR Calculation    O(N)           O(N)          O(N)
Space               O(N)           O(N)          O(N)

* Recent: O(1)-O(log N), Old: O(N)
** Recent reviews clustered at root!
