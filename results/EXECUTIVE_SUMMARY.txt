KEY INSIGHTS
═══════════════════════════════════════════════════════════════════

1. DATA STRUCTURE CHOICE DRAMATICALLY IMPACTS PERFORMANCE
   → 289x difference just from changing data structure
   → Same algorithm, same data, different structure

2. THEORY MATCHES PRACTICE
   → O(N) search really grows linearly: 0.035ms → 0.291ms (8.3x)
   → O(log N) search stays constant: <0.001ms at all sizes
   → Textbook predictions validated with real data ✓

3. AVL TREE BALANCE IS EXCEPTIONAL
   → Height of 9 for 41K reviews (theory max: ~15)
   → Automatic rotations maintain optimal structure
   → Guarantees consistent performance ✓

4. TRADE-OFFS EXIST
   → AVL Tree: Fast reads, slower writes
   → Linear List: Fast writes, slow reads
   → RBT: Optimized for recency, high insertion cost
   → No "perfect" solution - choose based on workload!
